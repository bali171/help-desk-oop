## Описание

Консольная система Help Desk, демонстрирующая 4 принципа ООП:
инкапсуляцию, наследование, полиморфизм и абстракцию.

## Запуск

1. Установить JDK 17
2. Открыть проект в VS Code с Extension Pack for Java
3. Запустить `Main.java` (`Ctrl + F5`)

## Структура проекта

- `model/` — модель предметной области (Ticket, User, роли)
- `service/` — бизнес-логика (TicketService, NotificationService)
- `repository/` — хранение заявок

## Жизненный цикл заявки

NEW → IN_PROGRESS → RESOLVED → CLOSED
(или CANCELLED на любом этапе до закрытия)
